# CLAUDE.md

Context Reader — React 19 + TypeScript + Vite приложение для изучения языков через
интересное чтение, контекстные объяснения и тренировку сохранённых слов. Backend —
Vercel serverless functions, основное хранилище — Vercel Blob.

Сначала прочитай и соблюдай общие правила для всех AI-инструментов в `AGENTS.md`.
Главные источники контекста:

- `PROGRESS.md` — живой статус и handoff;
- `PRODUCT_OVERVIEW.md` — актуальный обзор продукта;
- `docs/content-system-v1.2/` — подробные продуктовые и технические контракты;
- `AI_PIPELINE.md` и `DESIGN.md` — специализированные решения.

## Параллельная работа через субагентов

В `.claude/agents/` определены субагенты под отдельные потоки работы этого проекта.
Используй их, когда задача явно попадает в один из потоков или когда действительно
нужно вести несколько независимых задач параллельно:

- **frontend** — компоненты/хуки/CSS в `src/` по `PLAN.md`/`DESIGN.md`.
- **content-writer** — тексты уроков на поддерживаемых языках и русскоязычные
  аннотации (`src/data/`, схема в `src/types/lesson.ts`, правила в
  `AI_PIPELINE.md`).
- **audio-pipeline** — TTS-скрипты, генерация озвучки и таймкодов (`scripts/`,
  `public/audio/`, `src/data/lessonTimestamps.json`).
- **reviewer** — read-only проверка по DESIGN.md/PLAN.md/доступности перед коммитом.

Если несколько агентов параллельно редактируют файлы, изолируй их рабочие деревья,
чтобы они не затирали изменения друг друга. Для read-only исследования это не нужно.
