# Тренировка слов — визуальные артефакты (2026-07-28)

Самостоятельные HTML-файлы, каждый открывается прямо в браузере (двойной клик
или `open docs/training-plan/<файл>.html`) — без обращения к claude.ai, без
сборки проекта. Это визуальные мокапы для обсуждения формата, **не рабочий
код** — реализация ещё не начата, см. `PROGRESS.md` (раздел «2026-07-28»)
для решений и плана в текстовом виде.

Порядок просмотра — от первого черновика до финальной версии:

1. **`01-prototype-whole-phrase.html`** — исходный прототип (2026-07-24).
   Формат «перевод целиком»: русская фраза → печатаешь перевод на целевом
   языке. **Устарел** — формат заменён на клоуз, см. файл 03. Оставлен для
   истории решения (видно, от чего отказались и почему).
2. **`02-phrase-source-variants.html`** — три способа получить короткую фразу
   для тренировки из длинного предложения урока (обрезка / переписать-заново
   / как есть целиком), проверено на 5 реальных сохранённых словах. Вывод:
   нужен AI-шаг для части слов, простой обрезкой не обойтись.
3. **`03-cloze-practice-screen.html`** — актуальный (финальный) экран
   упражнения: русское предложение с выделенным словом сверху, пропуск на
   целевом языке снизу, тап по любому другому слову за переводом+озвучкой,
   подсказка-тоггл с необратимой пометкой «уже засчитано».
4. **`04-srs-verdict-mapping.html`** — как каждый вердикт/действие
   (Верно/Почти/Не совсем/Подсказка/Пропустить/Повтор/Тап) отражается на
   `repetitions`/`intervalDays`/`easeFactor`/`lapses`.

**Важно про файл 4**: текст внутри самого артефакта ещё описывает старое
поведение кнопки «Пропустить» («уходит в конец этой же сессии»). Финальное
решение — другое: слово убирается из очереди текущей сессии практики
**целиком** и появляется только в следующей (см. `PROGRESS.md` — там же
объяснено, почему сам файл в этом месте не переписывался, и как это должно
работать по факту).
